Guardar órdenes en el hosting

Usa una API privada PHP + MySQL, sin afectar la demo local ni el portal actual.

Uso seguro: hasta configurar el hosting, los datos permanecen guardados solamente en este navegador. Para guardar en servidor necesitas HTTPS, base de datos y un usuario con contraseña. La sincronización es manual para evitar cambios accidentales.
